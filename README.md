# AiDocInsight

AI-powered document insight platform. Phase 1: project foundation and authentication.

## Structure

- `frontend/` — React + Vite + Tailwind CSS
- `backend/` — Node.js + Express + MongoDB (MVC/service architecture)

## Quick start

See environment variables and run instructions in the phase summary, or:

```bash
# Backend
cd backend
cp .env.example .env
npm install
npm run dev

# Frontend (new terminal)
cd frontend
cp .env.example .env
npm install
npm run dev
```
